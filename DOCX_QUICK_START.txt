TROUBLESHOOTING
───────────────
Q: "python-docx not installed"
A: pip install python-docx

Q: "PyPDF2 not installed"  
A: pip install PyPDF2

Q: Document stuck at "processing"
A: Check backend logs for errors
   Common: ImportError, file permissions

Q: "DOCX parsed successfully" not in logs
A: python-docx not in correct Python env
   Use same Python that runs uvicorn

Q: Empty text extracted
A: DOCX may have no text paragraphs
   Check file is valid DOCX format
