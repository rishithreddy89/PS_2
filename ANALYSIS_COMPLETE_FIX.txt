PROBLEM RESOLVED

❌ Before: Frontend GET → Backend POST → 405 Method Not Allowed
✅ After:  Frontend POST → Backend POST → 200 OK
           Frontend EventSource → Backend GET stream → SSE

THE FIX
───────
Split single streaming POST endpoint into two separate endpoints:

1. POST /analyze  → Start analysis (non-blocking)
2. GET /stream    → Stream progress (SSE compatible)

This architecture allows:
  • POST for state-changing operations (RESTful)
  • GET for read-only streaming (EventSource compatible)
  • Proper HTTP semantics
  • Error handling before streaming

API ENDPOINTS (After Fix)
──────────────────────────

1. Start Analysis
   ═══════════════
   POST /api/v1/analysis/cases/{case_id}/analyze
   
   Validates:
     ✓ Case exists (404 if not)
     ✓ Has indexed documents (400 if none)
     ✓ Not already running (409 if duplicate)
   
   Returns immediately:
     {
       "case_id": "abc123",
       "status": "started",
       "message": "Analysis workflow started",
       "stream_url": "/api/v1/analysis/cases/abc123/stream"
     }

2. Stream Progress
   ═══════════════
   GET /api/v1/analysis/cases/{case_id}/stream
   
   Content-Type: text/event-stream
   
   Streams events:
     • workflow_started
     • planning_started
     • planning_completed
     • orchestration_started
     • agent_completed (per agent)
     • orchestration_completed
     • workflow_completed
     • workflow_failed

3. Get Status
   ════════════
   GET /api/v1/analysis/cases/{case_id}/analysis/status
   
   Returns:
     {
       "execution_id": "exec123",
       "status": "running|completed|failed",
       "duration_ms": 5432,
       "error": null,
       "created_at": "2024-01-01T12:00:00"
     }

ERROR SCENARIOS
───────────────

No Documents:
  Request: POST /analyze
  Response: 400 Bad Request
  Body: {"detail": "No indexed documents found for this case."}
  Action: Show error, prompt user to upload documents

Case Not Found:
  Request: POST /analyze
  Response: 404 Not Found
  Body: {"detail": "Case not found"}
  Action: Show error, redirect to cases list

Already Running:
  Request: POST /analyze
  Response: 409 Conflict
  Body: {"detail": "Analysis is already running for this case."}
  Action: Show "Analysis in progress", connect to stream

Stream Error:
  EventSource: onerror
  Action: Show "Connection lost", offer retry

VALIDATION LOGIC
────────────────

Before Starting Analysis:

1. Case Validation:
   SELECT * FROM cases WHERE id = ?
   → If not found: HTTP 404

2. Document Check:
   SELECT * FROM case_documents
   WHERE case_id = ? AND meta_data->>'status' = 'indexed'
   → If none: HTTP 400

3. Duplicate Check:
   SELECT * FROM planner_executions
   WHERE case_id = ? AND status IN ('pending', 'running')
   ORDER BY created_at DESC LIMIT 1
   → If found: HTTP 409

4. All Valid:
   → HTTP 200, start workflow
