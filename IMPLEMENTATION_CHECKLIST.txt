## Architecture Verification

### Data Flow: Upload → Index → Retrieve

```
┌────────────────────────────────────────────────────────────┐
│                   Frontend (React)                          │
│              DocumentUpload Component                       │
└────────────────────┬─────────────────────────────────────┘
                     │ POST /api/v1/documents/cases/{id}/documents
                     ↓
┌────────────────────────────────────────────────────────────┐
│            Backend (FastAPI) - documents.py                │
│           ✓ Validate file                                  │
│           ✓ Save to disk                                   │
│           ✓ Create DB record                               │
└────────────────────┬─────────────────────────────────────┘
                     │ async: ingest_file()
                     ↓
┌────────────────────────────────────────────────────────────┐
│         Ingestion Service - ingestion.py                   │
│           ✓ Read file (DOCX/PDF/TXT/MD)                   │
│           ✓ Parse content                                  │
│           ✓ Chunk text                                     │
│           ✓ Call embedding service                         │
└────────────────────┬─────────────────────────────────────┘
                     │ await embed_batch()
                     ↓
┌────────────────────────────────────────────────────────────┐
│    Local Embedding Service - local_embedding.py            │
│           ✓ Load model (all-MiniLM-L6-v2)                 │
│           ✓ Generate embeddings (384-dim)                  │
│           ✓ Return to ingestion                            │
│           ✗ NO API calls to OpenAI                         │
└────────────────────┬─────────────────────────────────────┘
                     │ embeddings, chunks
                     ↓
┌────────────────────────────────────────────────────────────┐
│       ChromaDB Service - chroma_service.py                 │
│           ✓ Store chunks with embeddings                   │
│           ✓ Index in vector DB                             │
│           ✓ Return to ingestion                            │
└────────────────────┬─────────────────────────────────────┘
                     │ complete
                     ↓
┌────────────────────────────────────────────────────────────┐
│       Document Router - documents.py                       │
│           ✓ Update DB record (status: indexed)             │
│           ✓ Return 201 Created                             │
└────────────────────┬─────────────────────────────────────┘
                     │ JSON response
                     ↓
┌────────────────────────────────────────────────────────────┐
│                   Frontend (React)                          │
│              DocumentList Component                        │
│           ✓ Refresh list every 3 sec                       │
│           ✓ Show "indexed" status                          │
└────────────────────────────────────────────────────────────┘
```

### Key: ✗ NO API calls to OpenAI during upload

## Rollback (If Needed)

If you need to revert to OpenAI embeddings:

```python
# Change in ingestion.py:
# FROM:
from app.knowledge.local_embedding import get_local_embedding_service
self.embedding_service = get_local_embedding_service()

# TO:
from app.knowledge.embedding import get_embedding_service
self.embedding_service = get_embedding_service()

# Change in retrieval.py similarly
```

But we recommend staying with local embeddings - it's faster, cheaper, and works offline!

See MIGRATION_GUIDE.txt for detailed troubleshooting steps.

- Model download slow? → Normal, ~60MB one-time
- High memory? → Normal, ~400MB for model
- DOCX won't parse? → Run `pip install python-docx`
- Slow embeddings? → Model runs on CPU, speed varies
- Still seeing OpenAI calls? → Check you imported from local_embedding
