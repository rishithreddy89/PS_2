## API Endpoints Added

```
Documents:
  POST   /api/v1/documents/cases/{case_id}/documents
  GET    /api/v1/documents/cases/{case_id}/documents
  DELETE /api/v1/documents/{document_id}

Analysis:
  POST   /api/v1/analysis/cases/{case_id}/analyze
  GET    /api/v1/analysis/cases/{case_id}/analysis/status

Review:
  POST   /api/v1/review/recommendations/{rec_id}/review
  GET    /api/v1/review/recommendations/{rec_id}/reviews
```

## How It Works

### 1. Upload Document
```
User clicks → Select files → Upload → Parse → Chunk → Embed → Index → Done
Time: ~8 seconds
```

### 2. Generate Analysis
```
User clicks → Planner → Select agents → Execute → Generate recs → Display
Time: ~30-60 seconds
Streaming: Live updates via Server-Sent Events
```

### 3. Request Review
```
User clicks → Show details → Select decision → Add comments → Submit → Update memory
Time: ~5 seconds
```
