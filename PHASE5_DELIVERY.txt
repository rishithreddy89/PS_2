================================================================================
API USAGE EXAMPLES
================================================================================

1. ANALYZE CASE
   curl -X POST http://localhost:8000/api/v1/nba/analyze \
     -H "Content-Type: application/json" \
     -d '{
       "case_id": "case-123",
       "query": "Provide next best actions",
       "include_memory": true
     }'

2. GET RECOMMENDATIONS
   curl http://localhost:8000/api/v1/nba/recommendations/case-123

3. GET EXPLANATIONS
   curl http://localhost:8000/api/v1/nba/explanations/case-123

4. SUBMIT FEEDBACK
   curl -X POST http://localhost:8000/api/v1/nba/feedback \
     -H "Content-Type: application/json" \
     -d '{
       "recommendation_id": "rec-123",
       "user_id": "user-456",
       "decision": "approved",
       "rating": 5,
       "comments": "Excellent recommendation"
     }'

5. PREPARE REVIEW
   curl -X POST http://localhost:8000/api/v1/nba/review?case_id=case-123
