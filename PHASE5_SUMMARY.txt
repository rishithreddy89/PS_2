🚀 HOW TO USE
================================================================================

QUICK START
-----------
1. Set your OpenAI API key:
   export OPENAI_API_KEY=your-key

2. Run the demo:
   ./quick-start-phase5.sh

MANUAL TESTING
--------------
1. Start the server:
   poetry run uvicorn app.main:app --reload

2. Analyze a case:
   curl -X POST http://localhost:8000/api/v1/nba/analyze \
     -H "Content-Type: application/json" \
     -d '{"case_id": "case-123", "query": "Analyze case"}'

3. Get recommendations:
   curl http://localhost:8000/api/v1/nba/recommendations/case-123

4. Submit feedback:
   curl -X POST http://localhost:8000/api/v1/nba/feedback \
     -H "Content-Type: application/json" \
     -d '{"recommendation_id": "rec-123", "user_id": "user-456", 
          "decision": "approved", "rating": 5}'

RUN TESTS
---------
./verify-phase5.sh

Or manually:
poetry run pytest tests/test_phase5.py -v

API DOCUMENTATION
-----------------
Visit: http://localhost:8000/docs
